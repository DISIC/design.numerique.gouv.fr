Tout ce qui est « visuellement apparent » (tendances, regroupements, motifs, valeurs aberrantes ou résultats significatifs) devraient au minimum, faire l'objet d'une description textuelle. Ces éléments peuvent également, de manière facultative, être restitués par sonification, par des moyens tactiles ou par d'autres approches multisensorielles.

<p class="fr-text--sm">Cette question est liée aux critères WCAG <a href="https://www.w3.org/WAI/WCAG22/Understanding/sensory-characteristics.html" lang="en">1.3.3 Sensory Characteristics (Level A)</a> et <a href="https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships" lang="en">1.3.1 Info and Relationships (Level A)</a>. Mais elle soulève un autre problème, encore non résolu. En effet, les sonifications ou les expériences tactiles sont souvent conçues parallèlement aux visualisations, de manière distincte. Par ailleurs, nous manquons également d'outils sémantiques pour décrire les relations entre les différents éléments (telles que les valeurs aberrantes, les comparaisons, les tendances, etc.) (voir la discussion <a href="https://github.com/w3c/aria/issues/991#issuecomment-668493619" lang="en">ARIA Data Visualisation module #991</a>). Bien que de nombreuses tentatives visent à automatiser les descriptions textuelles, pour le moment, le niveau de pertinence atteint n'est pas suffisant, comme le souligne les travaux de Lundgard <i>et al.</i></p>
