title: Modification de style par l'utilisateur non respectée
cat: 7
critical: true
origin: standard

Les modifications de style effectuées par l'utilisateur doivent être respectées.

Le graphique ne doit ni interférer avec les modifications de style (comme l'importation d'une feuille de style personnalisée pour une application HTML ou un site web) apportées par l'utilisateur, ni les outrepasser.
